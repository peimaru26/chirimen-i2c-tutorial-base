---

## これは何

M5Stack の TVOC/eCO2 ガスセンサユニット（SGP30）を、CHIRIMEN の Web I2C API から
動かすためのドライバーと、その使用例です。

センサーから取れるもの:

|                      | 内容                                              | 単位         |
| -------------------- | ------------------------------------------------- | ------------ |
| eCO2                 | CO2 相当値（換気の指標。本物の CO2 濃度ではない） | ppm          |
| TVOC                 | 揮発性有機化合物の総量                            | ppb          |
| raw H2 / raw Ethanol | センサー素子の生信号                              | ティック     |
| シリアル番号         | 個体固有の ID（疎通確認用）                       | 16進12桁     |
| ベースライン         | 補正アルゴリズムの内部状態（保存・復元用）        | 不透明な数値 |

## 使い方

### 準備（初回だけ）

```sh
cd ~/chirimen-i2c-tutorial-base/SGP30
npm i
```

配線:

| ユニット側 | Raspberry Pi Zero      |
| ---------- | ---------------------- |
| 黒 GND     | 6番ピン (GND)          |
| 赤 VCC     | **1番ピン (3.3V)**     |
| 黄 SDA     | 3番ピン (GPIO2 / SDA1) |
| 白 SCL     | 5番ピン (GPIO3 / SCL1) |

> [!IMPORTANT]
> **VCC は Raspberry Pi の 3.3V ピン（1番）に接続してください。5V ピンではありません。**
>
> このユニットは 5V と表示されていますが、基板上のレベルシフタ（BSS138）の高圧側プルアップが
> コネクタの VCC ピンに接続されているため、**I2C のロジックレベルは VCC に与えた電圧そのままに
> なります。** 5V を与えると Pi の SDA/SCL に 5V が乗り、GPIO を破損させるおそれがあります。
>
> SGP30 チップ本体は 1.8V 動作ですが、基板上の LDO（RT9193-1.8V）が生成するため、
> VCC は 3.3V で問題ありません。

配線が正しいかの確認:

```sh
i2cdetect -y 1
```

`58` が表示されればセンサーが見えています。表示されなければ配線か電源の問題で、
プログラムの問題ではありません。

### 基本の測定

```sh
node main.js
```

止めるときは `Ctrl + C`。

出力例:

```
serial number: 000001f9293c
eCO2: 400 ppm, TVOC: 0 ppb, raw H2: 13429, raw Ethanol: 17865
eCO2: 400 ppm, TVOC: 0 ppb, raw H2: 13445, raw Ethanol: 17736
```

**起動から15秒は eCO2 = 400 / TVOC = 0 の固定値です。** センサーが測定していない期間なので、
息を吹きかけても動きません。15秒待ってから試してください。

### ベースラインの検証

```sh
node main_baseline.js
```

ドライバーの実装が正しいかを自動チェックします。**普段の測定には使いません。**
ドライバーを書き換えたあとに実行して、壊れていないことを確認するためのものです。

15秒ほど待つと3行が出て、すべて通れば成功です:

```
[15s] ... baseline: {"eCO2":38198,"tvoc":39550}
probe: { eCO2: 4660, tvoc: 22136 } -> { eCO2: 4660, tvoc: 22136 }
restore: { eCO2: 38198, tvoc: 39550 } -> { eCO2: 38198, tvoc: 39550 }
パラメータ順・書き込み・復元をすべて確認しました
```

## 出力の読み方

| 見えているもの                      | 意味                                             |
| ----------------------------------- | ------------------------------------------------ |
| `eCO2: 400 ppm, TVOC: 0 ppb` が続く | 起動15秒以内（固定値）か、空気がきれい           |
| eCO2 が上がった                     | 空気が汚れた（人の呼吸、換気不足、アルコール等） |
| TVOC が上がった                     | 揮発性有機化合物が増えた                         |
| **raw が下がった**                  | ガス濃度が**上がった**（生信号は向きが逆）       |
| **raw が上がった**                  | ガス濃度が**下がった**                           |
| raw が起動直後に急上昇              | ヒーターの暖機中。ガスの変化ではない             |
| TVOC が 60000 で止まる              | 出力の上限に達した（センサーの限界ではない）     |
| eCO2 と raw が同じ方向に動く        | **実装がおかしい**（本来は逆相関する）           |

**eCO2 は本物の CO2 濃度ではありません。** アルコールを近づけると CO2 が増えていないのに
数千 ppm を示します。換気の指標としては使えますが、CO2 濃度計としては使えません。
理由は `VALUES_GUIDE.md` に書いてあります。

## 動作確認のやりかた

センサーが本当に生きているかを確かめる手順。**必ず起動から15秒待ってから**行います。

| やること                                       | 起きること                       | 戻るまで |
| ---------------------------------------------- | -------------------------------- | -------- |
| **息を吹きかける**                             | eCO2 が 400 → 1500 程度          | 数十秒   |
| **アルコール系のウェットティッシュを近づける** | TVOC が数千〜万 ppb              | 数分     |
| エタノールを塗った手をかぶせる                 | TVOC が上限（60000 ppb）付近まで | 5分以上  |

**推奨は「息を吹きかける」です。** 反応が十分に出て、回復も早いです。

エタノールで飽和させるのは効果が派手ですが、回復に時間がかかり、
繰り返すとセンサーの特性に影響しうるので、動作確認の常用にはしないでください。

### 反応が見えないときのチェック

1. 起動から15秒経っているか（**これが一番多い原因**）
2. `raw H2` の値は動いているか。動いていれば通信は正常
3. 直前に大きく振らせていないか（ベースラインが高い位置にいると小さな変化が埋もれます）

## 困ったとき

| 症状                                    | 原因                                   | 対処                                                                  |
| --------------------------------------- | -------------------------------------- | --------------------------------------------------------------------- |
| `i2cdetect` に `58` が出ない            | 配線、電源                             | 赤線が **3.3V ピン（1番）** に入っているか。**5V ピンではありません** |
| `this is not an SGP30 ...`              | 別のデバイスに繋がっている             | I2C アドレス（`0x58`）と配線を確認                                    |
| `CRC error on command ...`              | 接触不良、ノイズ                       | ケーブルの挿し直し。配線を短くする                                    |
| `Call init() first.`                    | `init()` を呼ばずにメソッドを使った    | コードの順序を確認                                                    |
| `ベースラインが 60 秒待っても有効に...` | センサーが応答しているが状態が進まない | 電源を入れ直してやり直す                                              |
| ずっと `400 ppm / 0 ppb`                | 15秒経っていない、または空気がきれい   | 15秒待ってから息を吹きかける                                          |
| 値がおかしい（エラーは出ない）          | 定数の写し間違い、バイト順             | `node main_baseline.js` を実行して検証が通るか見る                    |
